## 💡 프로젝트 소개

**약간(YAKKAN)** 은 개인정보 처리방침을 전부 읽게 하지 않고, 다른 서비스와 비교해 과도하거나 위험한 수집·활용 지점만 빠르게 보여주는 약관 분석 서비스입니다.

디지털 취약계층은 길고 어려운 약관으로 인해 본인도 모르게 과도한 개인정보 수집·활용에 동의하는 경우가 많습니다.

약간(YAKKAN)은 약관을 **전부 읽게 하거나 해석해주는 서비스가 아니라**, 다른 서비스와의 **비교를 통해 위험한 지점만 명확히 보여줌으로써** 사용자가 스스로 판단하고 안전하게 가입할 수 있도록 돕는 **최소한의 디지털 방어선**을 제공하는 것을 목표로 합니다.

<br/>

### 1️⃣ 약관 분석 (Core)

<img width="1920" height="1080" alt="아스키톤-약간(YAKKAN) pptx (1)" src="https://github.com/user-attachments/assets/7576b8af-a08b-4de8-af2a-aa3f5049b70d" />
<img width="1920" height="1080" alt="아스키톤-약간(YAKKAN) pptx (2)" src="https://github.com/user-attachments/assets/563cdb36-a10b-413c-b880-f2d7937f67f3" />
<img width="1920" height="1080" alt="아스키톤-약간(YAKKAN) pptx (3)" src="https://github.com/user-attachments/assets/d44e6c41-2b37-494d-bad1-fdd1e8bb15aa" />

> 입력한 약관에서 수집하는 개인정보 항목을 추출한 뒤, 얼마나 많은 기업들이 자신들의 약관에서 해당 개인정보를 수집하는지 퍼센트로 보여줍니다.

> 유사한 다른 서비스 대비 평균보다 많은 개인정보를 수집하거나, 비교적 보편적이지 않은 항목을 요구하는 등 잘 보이지 않았던 ‘약간’ 이상한 약관들을 하이라이트하며, 사용자가 시각적 자료를 통해 스스로 위험을 판단할 수 있도록 돕습니다.

 <br/>
