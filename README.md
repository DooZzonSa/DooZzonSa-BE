## 💡 프로젝트 소개

**약간(YAKKAN)** 은 개인정보 처리방침을 전부 읽게 하지 않고, 다른 서비스와 비교해 과도하거나 위험한 수집·활용 지점만 빠르게 보여주는 약관 분석 서비스

## 🎯 핵심 가치

디지털 취약계층은 길고 어려운 약관으로 인해 본인도 모르게 과도한 개인정보 수집·활용에 동의하는 경우가 많다.

약간(YAKKAN)은 약관을 **전부 읽게 하거나 해석해주는 서비스가 아니라**, 다른 서비스와의 **비교를 통해 위험한 지점만 명확히 보여줌으로써** 사용자가 스스로 판단하고 안전하게 가입할 수 있도록 돕는 **최소한의 디지털 방어선**을 제공하는 것을 목표로 한다.
